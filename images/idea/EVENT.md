# 🎪 이벤트 캘린더

> 기간 한정 이벤트와 시즌 콘텐츠를 관리하는 시스템입니다.

---

## 📌 이벤트 종류

### 1. 정기 이벤트 (매월)
| 이벤트 | 기간 | 내용 | 보상 |
|--------|------|------|------|
| 🌸 봄 축제 | 3~4월 | 벚꽃 데이터 조각 수집 | 에픽 펫 |
| ☀️ 여름 방학 | 7~8월 | 여름 한정 아이템 판매 | 전설 아이템 |
| 🍂 가을 학기 | 9~10월 | 도서관 보상 2배 | 레어 펫 |
| ❄️ 겨울 방학 | 12~1월 | 출석 보상 2배 | 에픽 아이템 |

### 2. 특별 이벤트
| 이벤트 | 내용 | 보상 |
|--------|------|------|
| 🎂 중앙대 개교기념일 | 기념 퀘스트 | 전설 펫 |
| 🐉 푸앙이 생일 | 호감도 2배 | 전설 아이템 |
| 🎃 할로윈 | 이면 세계 특수 몬스터 | 에픽 펫 |
| 🎄 크리스마스 | 특별 선물 교환 | 전설 아이템 |

### 4. 이벤트 보상 수령
- 이벤트 목표 달성 시 우편함으로 보상 발송
- 기간 내 미수령 시 자동 소멸

---

## 📌 구현 메모

- 이벤트 데이터는 JS 배열로 하드코딩 (간단 구현)
- 이벤트 진행도는 localStorage 저장
- 시작/종료일은 `Date.now()` 로 자동 판별
- 추후 백엔드에서 실시간 이벤트 관리
