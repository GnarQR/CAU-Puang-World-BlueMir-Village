# 🏅 명예의 전당 / 랭킹

> 플레이어들의 다양한 기록을 순위로 보여주는 시스템입니다.
> ⚠️ 백엔드 연동 필요 — 1단계는 더미 데이터로 UI만 구현

---

## 📌 랭킹 카테고리

### 1. 데이터 조각 랭킹
- 총 획득한 데이터 조각 수 기준
- 주간 / 전체 전환 가능

### 2. 호감도 랭킹
- 푸앙이 호감도 기준
- 호감도 MAX 달성자 명예의 전당 등재

### 3. 전투 랭킹
- 전투 승리 횟수 기준
- 보스 클리어 횟수 별도 표시

### 4. 수집 랭킹
- 보유 아이템 + 펫 총 개수 기준

### 5. 시즌 랭킹
- 매월 1일 초기화
- 시즌 1위 → 전설 펫 지급
- 시즌 2~3위 → 에픽 펫 지급
- 시즌 TOP 10 → 희귀 칭호 지급
