# 📰 공지 / 소식

> 게임 업데이트 소식과 운영자 공지를 확인하는 공간입니다.

---

## 📌 주요 기능

### 1. 공지 종류
| 종류 | 내용 |
|------|------|
| 📢 업데이트 | 새 기능, 아이템 추가 소식 |
| 🎊 이벤트 | 기간 한정 이벤트 안내 |
| 🔧 점검 | 서버 점검 일정 |
| 🎁 보상 | 공지 확인 시 보상 지급 |
| 🐛 버그 수정 | 버그 수정 내역 |

### 2. 공지 UI

```
┌──────────────────────────────────┐
│ 📰 공지 / 소식                   │
│                                  │
│ 🎊 [이벤트] 봄맞이 이벤트 시작!  │
│    2026.05.01 ~ 2026.05.31       │
│    보상: 에픽 펫 1마리            │
│                        [확인]     │
│                                  │
│ 📢 [업데이트] v1.2 패치노트       │
│    2026.04.28                    │
│    - 체육관 추가                  │
│    - 버그 수정 3건                │
│                        [확인]     │
└──────────────────────────────────┘
```

### 3. 공지 보상
- 특정 공지 확인 시 데이터 조각 지급
- 공지 1개당 최대 1회만 수령 가능

---

## 📌 구현 메모

- 공지 데이터는 JS 배열로 하드코딩 (간단 구현)
- 추후 백엔드에서 공지 관리 시스템 구축
- 공지 확인 여부는 localStorage 저장
