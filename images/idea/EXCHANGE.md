# 🏪 데이터 조각 거래소

> 플레이어 간 아이템을 거래할 수 있는 장터입니다.
> 동물농장의 중고 장터에서 영감을 받았습니다.
> ⚠️ 백엔드 연동 필요 — 1단계에서는 더미 데이터로 UI만 구현

---

## 📌 주요 기능

### 1. 아이템 등록
- 보유 중인 아이템을 거래소에 등록
- 원하는 가격 (데이터 조각) 설정
- 등록 가능 수량 제한 (기본 3개 슬롯)

### 2. 아이템 구매
- 다른 플레이어가 등록한 아이템 구매
- 카테고리별 필터 (음식 / 착용 / 꾸미기 / 펫)
- 가격순 / 최신순 정렬

### 3. 거래 수수료
- 거래 성사 시 판매 금액의 10% 수수료 차감
- 예: 💎 10개짜리 아이템 판매 시 실수령 💎 9개

### 4. 거래소 UI 구성

```
[ 전체 ] [ 음식 ] [ 착용 ] [ 꾸미기 ] [ 펫 ]   ← 카테고리 탭

┌─────────────────────────────────┐
│ 🍱 중앙대 도시락                 │
│ HP +30 · SP +15                 │
│ 판매자: 익명                     │
│ 💎 4개                  [구매]  │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ 🐱 캠퍼스 고양이 (펫)            │
│ 데이터 조각 +1 (매일)            │
│ 판매자: 익명                     │
│ 💎 8개                  [구매]  │
└─────────────────────────────────┘
```

### 5. 거래 제한
- 전설 등급 아이템 / 펫은 거래 불가
- 1일 구매 한도 💎 200개
- 같은 아이템 중복 등록 불가
