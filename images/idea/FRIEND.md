# 👥 친구 목록

> 다른 플레이어와 친구를 맺고 방문하는 시스템입니다.
> ⚠️ 백엔드 연동 필요

---

## 📌 주요 기능

### 1. 친구 추가
- 닉네임으로 친구 검색 및 신청
- 친구 신청 수락/거절
- 최대 친구 수 50명

### 2. 친구 목록
- 온라인/오프라인 상태 표시
- 마지막 접속 시간 표시
- 친구 호감도, 레벨 확인

### 3. 친구 연구실 방문
- 친구 연구실 구경 가능
- 방문 시 친구에게 데이터 조각 +1 지급
- 하루 5명까지 방문 가능

### 4. 친구 선물
- 음식 아이템 선물 가능 (착용/펫 불가)
- 하루 3개까지 선물 가능
- 선물 받으면 우편함으로 전달
