# 📬 우편함

> 친구에게 아이템을 선물하거나 시스템 보상을 수령하는 공간입니다.
> ⚠️ 친구 선물 기능은 백엔드 연동 필요

---

## 📌 주요 기능

### 1. 받은 우편함
- 친구에게 받은 선물
- 시스템 보상 (퀘스트, 업적, 출석)
- 이벤트 보상
- 우편은 7일 후 자동 삭제

### 2. 보낸 우편함
- 내가 보낸 선물 내역
- 수령 여부 확인

### 3. 우편 종류
| 종류 | 발신자 | 내용 |
|------|--------|------|
| 🎁 선물 | 친구 | 음식 아이템 |
| 🏆 보상 | 시스템 | 퀘스트/업적 보상 |
| 🎊 이벤트 | 시스템 | 이벤트 보상 |
| 📢 공지 | 운영자 | 공지 + 보상 |

### 4. 우편함 UI

```
┌──────────────────────────────────┐
│ 📬 우편함 (3개 미확인)            │
│                          [전체수령]│
│                                  │
│ 🎁 푸앙마스터 → 나               │
│    🍪 푸앙이 쿠키 x1             │
│    1시간 전          [수령]       │
│                                  │
│ 🏆 시스템                        │
│    일일 퀘스트 완료 보상 💎 5개   │
│    2시간 전          [수령]       │
└──────────────────────────────────┘
```

## 📌 구현 메모

- 시스템 보상 우편은 localStorage로 구현 가능
- 친구 선물 우편은 백엔드 연동 필요
- 1단계: 시스템 보상 우편만 구현
