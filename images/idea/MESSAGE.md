# 💌 쪽지

> 친구와 1:1 메시지를 주고받는 시스템입니다.
> ⚠️ 백엔드 연동 필요

---

## 📌 주요 기능

### 1. 쪽지 보내기
- 친구 목록에서 쪽지 전송
- 최대 100자 입력 가능
- 하루 20통 발송 제한

### 2. 받은 쪽지함
- 읽지 않은 쪽지 알림 표시
- 쪽지는 30일 후 자동 삭제
- 최대 100통 보관 가능

### 3. 쪽지 UI

```
┌──────────────────────────────────┐
│ 💌 쪽지함 (2개 미확인)            │
│                                  │
│ 🔵 푸앙마스터                    │
│    "같이 이면 세계 가즈아!!"      │
│    30분 전           [답장]       │
│                                  │
│ 🔵 이면세계탐험가                 │
│    "데이터 조각 어떻게 모았어?"   │
│    2시간 전          [답장]       │
└──────────────────────────────────┘
```

### 4. 제한 사항
- 친구가 아닌 플레이어에게는 쪽지 불가
- 욕설/비방 필터링 적용 (추후 구현)
