# 🏡 내 연구실 — 플레이어 홈

> 플레이어만의 개인 공간입니다.
> 스탯 확인, 보유 아이템, 펫, 꾸미기 현황을 한눈에 볼 수 있습니다.

---

## 📌 주요 기능

### 1. 플레이어 정보
- 닉네임, 레벨, 경험치 표시
- HP / SP / 데이터 조각 현황
- 푸앙이 호감도

### 2. 보유 현황
- 인벤토리 (음식 아이템)
- 착용 중인 아이템
- 동행 중인 펫
- 구매한 꾸미기 아이템

### 3. 연구실 꾸미기
- 꾸미기 아이템으로 연구실 장식
- 구매한 아이템 적용/해제 가능
- 펫 배치 가능

### 4. 출석 보상
- 매일 접속 시 데이터 조각 지급
- 연속 출석일수에 따라 보상 증가

| 연속 출석 | 보상 |
|-----------|------|
| 1일 | 💎 2개 |
| 3일 | 💎 5개 |
| 7일 | 💎 10개 + 랜덤 음식 아이템 |
| 14일 | 💎 20개 + 랜덤 착용 아이템 |
| 30일 | 💎 50개 + 랜덤 펫 (일반) |

---
